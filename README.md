# 订阅业务收入成本监控看板 · 数据产品作品集

某海外 AI 创作平台的订阅制商业化监控：订阅会员 + 积分购买双轨收入，与模型调用、渲染、创作者分成等成本的统一核算与日级监控。

> **数据声明**：本看板全部为仿真数据。曲线形状参考真实业务趋势，数值已缩放与扰动，不对应任何真实经营数字。

## 看板内容

顶部导航提供四个业务线视图，即点即切，全部图表按当前视图重渲染：**总览 / 订阅线 ROI / 购买积分 / 成本与质量**。

| 板块 | 回答的问题 |
|---|---|
| 总览 KPI | 同解剖 KPI 卡（标题/数值/说明/迷你走势线）：窗口净收入、新增会员、期末 MRR、消耗、订阅与购买分摊成本 |
| 收入概览 | 每日净收入、每日新增付费会员，订阅上线日标注 |
| 双轨 ROI 对照 | 订阅线与购买线并排小倍数：各画「收入指数 vs 分摊成本指数」（区间首日=100），共用同一纵轴刻度与同一组图例，线距即毛利空间 |
| 订阅线 ROI（深挖） | 订阅收入/成本/毛利/期末 MRR 指标条；毛利逐日走势 + 7 日均线；期末 MRR 走势 |
| 购买积分（深挖） | 等效金额/分摊成本/单位积分成本指标条；等效金额与分摊成本逐日对照 |
| 购买成本 | 单位积分成本指数走势、三桶积分消耗的周度构成（分摊比例来源） |
| 单位成本钻取 | 点击成本指数任意日期，查看当日单位成本的模型级瀑布拆解 |
| 分摊与质量 | 成本四来源日级堆叠、成本四来源 → 三消耗桶的冲积分摊全景；逐日发布质量条 |

## 方法要点

- **成本分摊**：每日已纳入成本（模型网关调用、3D 渲染、创作者分成）× 各桶（购买/订阅/赠送）消耗占比，跨日只求和
- **单位成本**：区间分摊成本 ÷ 区间消耗，不做日均简单平均
- **质量底线**：数据校验未通过的日期不发布成本指标；报表与订单流水逐笔核对

## 交互清单

- **业务线视图切换**：顶部导航四视图（总览 / 订阅线 ROI / 购买积分 / 成本与质量）即点即切，图表按可见容器实际宽度重渲染；左侧章节导航与滚动高亮同步
- **时间窗口切换**：全量 / 近 30 天 / 近 14 天，全部图表与 KPI 联动重算
- **单位成本钻取**：点击「单位积分成本指数」折线任意日期（Enter 同样可达），瀑布图切到当日模型级拆解，再点取消
- **钻取逐日播放**：钻取状态下可 ◀/▶ 步进或自动逐日播放，观察单位成本逐日演变；点击图表即中断
- **图例点击显隐**：序列图例可点击/键盘切换显隐（隐藏后坐标轴自适应重算；至少保留一条序列）；双轨 ROI 两图共用同一组图例，任一序列显隐联动两张图并同步重算共用刻度
- **冲积图悬停**：悬停缎带或节点，高亮相关流量、压暗其余，读数显示分摊金额与占比
- **十字线读数**：折线/柱图悬停显示逐日数值；点击柱图日期可联动
- **主题切换**：深浅双主题，全部图表即时重绘（含冲积图缎带渐变）
- **章节导航**：左侧圆点导航 + 顶部导航随滚动高亮；长页右下角「回到顶部」按钮；入场动画遵循 `prefers-reduced-motion`

## 图表规范

配色为经 CVD 安全校验的分类色板（蓝/橙/青绿），颜色跟随实体（收入=蓝、成本=橙、购买等效=青绿），深浅两套独立校验；KPI 卡内置 12 点迷你走势线（弱化色 + 端点，颜色跟随所属实体）；双轨 ROI 对照采用共享刻度小倍数；细节遵循细标记、发丝网格、选择性直标等数据可视化规范。
