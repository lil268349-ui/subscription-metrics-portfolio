# 订阅业务收入成本监控看板 · 数据产品作品集

某海外 AI 创作平台的订阅制商业化监控：订阅会员 + 积分购买双轨收入，与模型调用、3D 渲染、创作者分成等成本的统一核算与日级监控。

> **数据声明**：本看板全部为仿真数据。曲线形状参考真实业务趋势，数值已缩放与扰动，不对应任何真实经营数字。

## 方法要点

- **成本分摊**：每日已纵向成本（模型网关调用、3D 渲染、创作者分成）× 各桶（购买/订阅/赠送）消耗占比，跨日只求和
- **单位成本**：区间分摊成本 ÷ 区间消耗，不做日均简单平均
- **人均 MRR 贡献**：当日 MRR ÷ 当日新增会员。分母是会员数（恒 >0），天然有界，不会被上线初期小基数打出悬崖；上行代表新增会员买高价计划的比例上升
- **质量底线**：数据校验未通过的日期不发布成本指标；报表与订单流水逐笔核对

## 交互清单

- **业务线视图切换**：顶部导航四视图即点即切；左侧章节导航与滚动高亮同步
- **时间窗口切换**：全部窗口 / 近 30 天 / 订阅上线以来，全部图表与 KPI 联动重算；另可在任一折线/堆叠图上拖选日期，切入自定义区间（导航栏 chip 可清除）
- **单位成本钻取**：点击「单位积分成本指数」折线任意日期，冲积图切到当日模型级拆解，再点取消
- **钻取逐日播放**：钻取状态下可 ◀/▶ 步进或自动逐日播放，观察单位成本逐日演变
- **图例点击显隐**：序列图例可点击/键盘切换显隐（隐藏后坐标轴自适应重算，至少保留一条序列）；双轨 ROI 两图共用同一组图例与同一刻度，显隐联动两图
- **冲积图悬停**：悬停缎带或节点，高亮相关流量、压暗其余，读数显示分摊金额与占比
- **十字线读数**：折线/柱图悬停显示逐日数值；图下统计条给出峰值/低点/均值/当前
- **日期下钻抽屉**：点击任一时间序列图的日期（或质量条格），右侧滑出当日全量拆解抽屉——收入、会员、成本分摊、成本四来源占比、数据质量五段，逐项带前一日环比（绿涨橙跌），支持 ‹ › 或 ←/→ 翻日、Tab 焦点锁在抽屉内、Esc/遮罩关闭
- **拖选自定义窗口**：在任一折线/堆叠图上按住拖选日期区间，全局切入自定义时间窗，导航栏出现可清除的区间 chip（与预设窗口互斥）；点选（≤6px 位移）仍走下钻，拖选与点选按位移自动分流
- **KPI 卡跳转**：点击 KPI 卡直接进入对应业务线深挖视图
- **主题切换**：深浅双主题，全部图表即时重绘
- **动效**：入场动画遵循 `prefers-reduced-motion`；长页右侧「回到顶部」按钮

## 图表规范

配色为经 CVD 安全校验的分类色板（蓝/橙/青绿），颜色跟随实体（收入=蓝、成本=橙、购买等效=青绿），深浅两套独立校验；KPI 卡内置 12 点迷你走势线（弱化色 + 端点）；双轨 ROI 对照各自归一刻度、以首日=100 基准虚线锚定，两线间的毛利空间以灰带呈现；趋势图支持条线组合——柱承载量级、均线承载走向，均线带同面色晕保证穿柱可读；堆叠图峰值上方按最近步长留白，不浪费纵向分辨率；细节遵循细标记、发丝网格、选择性直标等数据可视化规范。
